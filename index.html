Android Pour votre appareil

iPhone ou iPad Pour votre appareil

Ordinateur Windows Pour votre appareil
Chrome, Edge, Firefox : appuyez sur Ctrl + Maj + Suppr.
Mac Pour votre appareil
Chrome, Edge, Firefox : appuyez sur ⌘ + Maj + Suppr.
Safari : menu Historique → Effacer l'historique.

Si effacer tout l'historique risque d'attirer l'attention, supprimez seulement les pages de ce site. La navigation privée n'enregistre pas l'historique.

Vous cherchez du soutien ?

Vous n'êtes pas seule.

Des ressources gratuites et confidentielles sont disponibles pour les personnes qui vivent de la violence conjugale, du contrôle, des menaces ou une situation qui les met mal à l'aise ou en danger.

Vous êtes en danger immédiat ?

911

Appelez le 911 (police, ambulance). Si vous ne pouvez pas appeler, demandez à une personne de confiance de le faire pour vous.

Naviguez en toute sécurité

Si vous pensez que votre téléphone, votre ordinateur ou votre historique de navigation pourrait être surveillé, privilégiez, lorsque c'est possible, un appareil auquel cette personne n'a pas accès. Vous pouvez également effacer votre historique de navigation : appuyez sur ⋮ → Supprimer les données de navigation. Le bouton « Effacer l'historique », en haut de chaque page, donne les étapes pour votre appareil.
